# PrusaSlicer: настройка теста высоты магнитов

Для [magnet_fit_test.stl](../print/petg/magnet_fit_test.stl), **Prusa MK4, сопло 0,4 мм, PETG**. [Размеры карманов и применение теста](../print/README.md#тест-посадки-магнитов).

Цель — печатать основную часть слоем **0,20 мм**, а верхушки шести торцевых упоров — слоем **0,05 мм**. Так в нарезке сохраняется шаг высоты 0,05 мм без мелкого слоя по всей детали. Для точного числового интервала используйте **модификатор диапазона высот**, а не рисование адаптивного слоя мышью.

## 1. Импорт и базовые параметры

1. Включите **Экспертный режим / Expert**. Названия пунктов могут немного отличаться в зависимости от версии и языка PrusaSlicer; ниже приведены английские названия для поиска.
2. Выберите профиль **Original Prusa MK4 с соплом 0,4 мм** и отлаженный профиль используемого PETG.
3. Добавьте STL. Оставьте масштаб **100%**, уложите широким плоским дном на стол: отверстия, открытые карманы и надписи направлены вверх. Габарит должен быть **58,5×32×6,5 мм**, нижняя грань — на Z=0. При другой ориентации указанные ниже отметки Z не подходят.
4. В **Настройки печати → Слои и периметры / Print Settings → Layers and perimeters** установите:
   - **Layer height:** `0.20 mm`;
   - **First layer height:** `0.20 mm`;
   - **Perimeters:** `3`;
   - **Top solid layers:** `6`;
   - **Bottom solid layers:** `6`.
5. Заполнение — **20% Gyroid**, поддержки выключены. Температуры, поток, обдув и ретракты оставьте из профиля филамента. Не включайте сглаживание верхних поверхностей **Ironing** для этого измерительного теста.

## 2. Проверка разрешённой высоты слоя

Откройте **Настройки принтера → Экструдер 1 → Пределы высоты слоя / Printer Settings → Extruder 1 → Layer height limits**. Для верхнего участка профиль должен допускать **Min ≤ 0.05 mm**. Максимальный предел оставьте штатным.

Если нижний предел уже 0,05 мм или меньше, менять его не нужно. Если он выше, сохраните отдельную копию профиля для теста и задайте минимум `0.05 mm` только при использовании настроек печати, допускающих такой тонкий слой. Само изменение ограничения не подтверждает качество экструзии на 0,05 мм: при неподходящем профиле не считайте напечатанные ступеньки точным измерителем. Основные отлаженные профили не перезаписывайте.

## 3. Числовой диапазон для мелкого слоя

1. Если ранее использовали инструмент **Variable layer height**, сбросьте его профиль кнопкой **Reset**. Для этой детали задавайте высоту одним способом — через числовой диапазон.
2. Щёлкните правой кнопкой по модели или её имени в списке объектов.
3. Выберите **Модификатор диапазона высот / Height range modifier**.
4. В панели **Диапазоны высот / Height Ranges** задайте один интервал:

   | Поле | Значение |
   |---|---:|
   | Начало / Start, From | **6.20 mm** |
   | Конец / Stop, To | **6.60 mm** |
   | Высота слоя / Layer height | **0.05 mm** |

   Это высоты в миллиметрах от стола, а не номера слоёв. Конец 6,60 мм немного выше модели и покрывает все верхушки, включая самую высокую на Z=6,50 мм.
5. Если поле **Layer height** находится не в самой таблице, выберите созданный диапазон в списке объектов и найдите его параметры в правой панели. Пользуйтесь именно диапазоном высот; обычный куб-модификатор не заменяет эту настройку слоя.
6. Удалите лишние диапазоны, если они появились с другими значениями. Ниже Z=6,20 мм должна действовать базовая высота 0,20 мм.
7. Нажмите **Нарезать / Slice now**.

## 4. Проверка в предварительном просмотре

В **Preview** выберите раскраску **Layer height**. Основная часть должна иметь высоту слоя 0,20 мм, верхние 0,30 мм — 0,05 мм. Затем передвигайте вертикальный ползунок по одному слою и смотрите **Z слоя с экструзией**, а не высоту перемещения с подъёмом сопла.

Ожидаемые верхние отметки упоров:

| Подпись кармана | Высота над дном кармана | Последний слой упора, Z от стола |
|---:|---:|---:|
| 0.05 | 5,05 мм | **6,25 мм** |
| 0.10 | 5,10 мм | **6,30 мм** |
| 0.15 | 5,15 мм | **6,35 мм** |
| 0.20 | 5,20 мм | **6,40 мм** |
| 0.25 | 5,25 мм | **6,45 мм** |
| 0.30 | 5,30 мм | **6,50 мм** |

На Z=6,25 мм должны печататься все шесть высоких упоров. На Z=6,30 мм — пять, затем четыре, три, два; на Z=6,50 мм остаётся только упор кармана `0.30`. Упор `0.05` уже не должен получать экструзию выше 6,25 мм. Само дно под магнитами имеет номинальную толщину **1,20 мм**.

Если часть верхушек заканчивается на одной отметке, проверка высоты не готова: проверьте диапазон, минимум слоя, отсутствие другого профиля переменного слоя, масштаб и положение модели. При ручной проверке G-code ищите участки `;LAYER_CHANGE`, `;Z:` и `;HEIGHT:`, если эти комментарии присутствуют. Сохраните проект через **File → Save Project As…** в `.3mf`: этот формат сохранит модель вместе с диапазоном и настройками. Отдельный STL диапазон не хранит.

PrusaSlicer в этой рабочей среде не установлен: инструкция сверена с документацией Prusa, но фактическую нарезку выбранным вами профилем нужно проверить по таблице выше.

## 5. Как использовать отпечаток

Дайте детали остыть. Вставляйте магнит в карманы без клея, подбирая боковую посадку; для извлечения нажимайте с обратной стороны через отверстие Ø5 мм. Высоту сравнивайте с верхом торцевого упора прямой линейкой и щупом. Например, при фактической толщине магнита ровно 5,00 мм в кармане `0.20` разница с упором должна составлять около 0,20 мм.

Это **открытая высотная база**, а не закрытый паз с потолком. Шаг слоёв 0,05 мм сохраняет различие отметок в G-code, но не гарантирует абсолютную точность печати ±0,05 мм. Фактическая толщина магнита также влияет на результат.
