# Архив CAD

Файлы сохранены без изменения содержимого. `nut.sc`, `knob.sc`, `magnet.sc` и `mic_primitive.sc` — отдельные архивные копии общих компонентов: относительные ссылки старых сборок остаются рабочими.

Актуальные сборки лежат на уровень выше: `../Fifine_Clamp_V1.sc` и `../Fifine_Clamp_Right_V1.sc`. Актуальные STL — в `../../print/`.
